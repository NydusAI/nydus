Provision a new Snowflake database with proper access controls,
schemas, and warehouse bindings from scratch.

Steps:
1. Create the database and set the default retention period
2. Define schemas (raw, staging, analytics) with managed access
3. Create a dedicated virtual warehouse and configure auto-suspend/resume
4. Grant role-based privileges using a functional role hierarchy
5. Validate connectivity and run a smoke-test query against each schema
